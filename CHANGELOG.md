# Changelog

All notable changes to NeonPlug are documented here.

This file is **generated by the release workflow** — each `## [YEAR.MONTH.N]` section
below is GitHub's auto-generated release notes for that tag, prepended by
`.github/workflows/release.yml`. Hand-edit a released section only to add context a
PR title didn't convey; write anything else under `## [Unreleased]` and it will be
carried into the next release.

The file is bundled into the app (About tab → What's new), so it travels with the
offline single-file build. Keep entries short enough to read in that panel.

Versions are `YEAR.MONTH.N`: the year and month a release was cut, and N counting
that month's releases from 0 — `2026.9.0`, then `2026.9.1`, then `2026.10.0`. A
version says how old a build is, not how big its changes are. Whether a saved
`.neonplug` file still loads is decided by the file's own format version.

## [0.1.0] — 2026-08-05

Baseline. Everything prior to the introduction of tagged releases, summarised:

- Radio support: DM-32UV / DP570UV (DMR, 4000 ch, zones, contacts, scan lists),
  UV5R-Mini (analog, BLE + serial), FT-65, FT-4, FT-25R (Yaesu SCU-35 clone protocol).
- Channels, zones, scan lists, contacts, DMR IDs, and a declarative Settings tab
  driven per model by capabilities rather than model-name checks.
- Import sources: CSV, airports (with common aircraft frequencies), TAFL, repeater
  databases, US state datasets, and the channel wizard.
- Single-file offline build — the deployed page doubles as the downloadable app.
- PR preview deploys under `/test/<branch>/`.
