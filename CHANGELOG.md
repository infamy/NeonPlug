# Changelog

All notable changes to NeonPlug are documented here.

This file is **generated by the release workflow** — each `## [YEAR.MONTH.N]` section
below holds GitHub's auto-generated release notes for that tag, prepended by
`.github/workflows/release.yml`. Hand-edit a released section only to add context a
PR title didn't convey. Write anything else under `## [Unreleased]`: the next release
moves it to the top of its section, above GitHub's list, and the About tab shows it
instead of that list.

The file is bundled into the app (About tab → What's new), so it travels with the
offline single-file build. Keep entries short enough to read in that panel.

Versions are `YEAR.MONTH.N`: the year and month a release was cut, and N counting
that month's releases from 0 — `2026.9.0`, then `2026.9.1`, then `2026.10.0`. A
version says how old a build is, not how big its changes are. Whether a saved
`.neonplug` file still loads is decided by the file's own format version.

## [2026.9.0] — 2026-09-13

- First tagged release. neonplug.app now serves the latest release, and
  neonplug.app/dev/ has the latest development build.
- Radios: DM-32UV / DP570UV, UV5R-Mini (USB or Bluetooth), and Yaesu FT-65, FT-4, FT-4VR
  and FT-25R. BTECH DA-7X2 / DA-7XR and AnyTone AT-D890UV are in alpha.
- Edit channels, zones, scan lists, contacts and settings. Save codeplugs as .neonplug
  files, or convert one for another radio.
- Build channel lists from CHIRP files, repeater lists, airports, TAFL and fixed channel
  sets, or with the Channel Wizard.
- Works offline as a single HTML file.
